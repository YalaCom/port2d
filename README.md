# Причал

Пиксельная игра про перекупа в порту (Phaser 3, без npm).

## Играть

**Рабочая ссылка:** https://yalacom.github.io/port2d/

Если чёрный экран — подождите 1 минуту после пуша и нажмите Ctrl+F5.

Локально: откройте `docs/index.html` (нужен интернет для CDN Phaser).

## Как играть

- ЛКМ — идти
- WASD / стрелки — идти вручную
- E — взаимодействие
- Пирс — купить / торг
- Палатка — цена и продажа
- Таверна — слухи
- Дом / кровать — новый день
