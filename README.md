# Причал

Пиксельная экономическая песочница в порту. Вид сверху ¾, сетка 16×16, клик-чтобы-идти.

## Играть

После деплоя Pages: https://yalacom.github.io/port2d/

Локально: откройте `docs/index.html` (нужен интернет для Phaser CDN).

## Управление

- ЛКМ по земле — путь
- E — взаимодействие
- WASD / стрелки — шаг
- Корабль — закуп и торг
- Палатка — витрина и цена
- Дом / кровать — конец дня
- Таверна — слухи и ужин

## Графика

Ассеты Stardew Valley копировать нельзя. Здесь оригинальный пиксель-арт в той же логике: nearest-neighbor, тёплая палитра, здания в ¾, ходьба на 4 стороны, вода, сортировка по Y, день/ночь.
